推荐原因这是 AI 自我改进用在科研上的一个具体例子，检验方法很聪明，能帮你判断「AI 做科研」的新闻到底有多少真进展。

elvis 推荐了一篇论文，介绍一个让 AI 做科研时能自我改进的框架 DiscoveryRSI。它的检验方式很巧：让模型提出科学假设，再看这些假设能不能对上模型训练截止之后才发表的真实研究。因为这些论文模型从来没见过，猜中就说明它确实推理出了新东西，而不是把背过的内容复述一遍。框架每跑完一轮就复盘哪些做法有效、哪些反复失败，再把改进应用到下一次研究中。在这个检验下，一个只有 270 亿参数的模型表现超过了 GPT-6 和 Claude Opus 5 这样的大模型。

核心要点

  • 在命中「训练截止后才发表的研究」这项检验上，这个 27B 模型达到 6.3%，而 GPT-6 只有 2.5%，Claude Opus 5 只有 2.3%，小模型反而领先一倍多。
  • 系统用多 Agent 进化搜索长出一棵假设树，再把选中的研究方向转成可以直接执行的任务。
  • 每次运行后它会给贡献最大的假设记功，并回放整个研究流程找出高产策略和重复失败，被采纳的改进才会用于新研究。
  • 自动评分的假设质量两轮后从 4.86 升到 5.39，提升最大的是可证伪性，实验覆盖四个生命科学领域。

评论总结

  • 亮点@shuangshuang90 和 @beshoyarmanios 认为用「训练截止后发表的研究」做检验很聪明，因为模型无法靠记忆作弊。
  • 疑问@beshoyarmanios 追问「命中」是怎么判定的：如果也由大模型来判，宽松打分可能同时抬高 6.3% 和对照组的数字。
  • 分歧@Kieren_PB_Day 和 @futureseemsgood 认为科研的稀缺环节从来不是想出假设，而是判断哪个假设最便宜就能被证伪，生成再多也只会堆满实验台。

Meta 的 ProPerAgent：不改模型，只管「什么时候开口」，主动助手准确率从 15% 到 38%↗

DAIR.AI @dair_ai13.5万 粉丝10月20日 04:26长帖

推荐原因你在用和关注 AI 助手，这项研究说明主动提醒类功能的关键不在模型多强，而在会不会闭嘴，对挑选或设计助手很有参考价值。

DAIR.AI 推荐 Meta 的一项研究，讨论那种会主动提醒你的 AI 助手该怎么设计。ProPerAgent 不改模型权重，只改记忆怎么递给模型、以及什么时候允许它开口。流程是先识别你眼前有什么东西，再拿这些东西去检索你过去的经历、偏好和限制，然后单独用一次模型调用判断：这些记忆是否值得现在打断你。如果不值得，就什么也不返回，模型保持沉默。研究的核心结论是，主动助手要成功，不仅回答要有用，时机也要对。

核心要点

  • 标准记忆方案的准确率最多约 15%，换上这套流程后达到 38%，整个过程没有重新训练模型。
  • 消融实验里去掉「判断是否值得打断」这一步，准确率从 37.3% 掉到 24.0%，说明这个过滤环节是提升的主要来源。
  • 在本该保持沉默的片段上，它多余插话的比例降到 15.3%，而普通的检索增强方案在两种测试模式下分别高达 77.3% 和 84.0%。
  • 开源的 Qwen3.8-27B 不训练就能达到 37.5%，再用强化学习惩罚过早和重复的插话，能进一步提到 42.4%。

评论总结

  • 共识多位读者（如 @tylereptgames、@AnwarTimilla）认为真正的结论是「知道什么时候闭嘴」，普通方案 77% 的多余插话太夸张。
  • 疑问@098uyiubgvgcss 和 @CloudDogx 指出 15% 到 38% 的提升同时改了证据和时机两件事，希望论文单独报告时机判断贡献了多少。
  • 亮点@liuzhao_666 补充，主动助手还需要记住自己已经提醒过什么，否则同一件事说三遍也会变成打扰。

最近 Claude 封号严重，很多人在本地层层叠加换 IP、改设备指纹之类的伪装。实践哥换了个思路：不再折腾本地环境，而是在新加坡放一台 Mac mini（也可以租一台 VPS），Claude 和 Claude Code 都在那台机器上运行，国内的电脑和手机只通过网易 UU 远程去接管操作。他选新加坡是因为和北京在同一时区、物理距离近，而且本身就在 Anthropic 的支持地区名单里。这篇是他 30 天实测的第 5 天记录，他明确说不为任何租赁商家背书、也不保证账号一定不被封，文中的虚拟卡申请链接带推广性质。

核心要点

  • 他这条线路实测远程延迟约 70 毫秒，打字、切窗口、看 Claude Code 输出都很跟手，UU 里还能直接开终端，不必每次打开完整桌面。
  • 机器的具体设置是把系统时区改成 Asia/Singapore、打开定位服务，Claude Desktop 正常安装，Claude Code 用官方安装命令装好后完成登录。

  • 他顺手开源了 uu-term-bridge：Mac 上 iTerm2 新开的终端会同步出现在手机 UU 里，手机新建终端约两秒后 Mac 也会自动弹出窗口。
  • 没有 Mac mini 也可以，一台新加坡 Linux VPS 配合 SSH 和 tmux 就能跑 Claude Code，断开连接后会话仍在后台继续。
