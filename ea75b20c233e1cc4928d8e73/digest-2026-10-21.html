DeepSeek 把线上在用的推理框架 DeepInfer 开源了，连对齐官方 API 的编解码组件也一起放出↗

DeepSeek @deepseek_ai117.8万 粉丝10月20日 17:30

赞 3.4万转 0评 1,290阅 421.9万

推荐原因这是今天关注圈里讨论最多的一件事，看懂它能帮你判断国产模型 API 后面还会不会继续降价，以及自建部署到底难在哪。

DeepSeek 把支撑 V4.1-Flash 大规模线上服务的自研推理框架 DeepInfer 开源，并同时开源配套组件 deepseek-recipe。模型权重好比一本菜谱，推理框架则是后厨的出餐系统：负责接请求、排队、在显卡上把答案算出来，调度得好，同样的显卡能多服务几倍的用户。DeepSeek 说开源这套生产栈，是为了帮业界省算力、省电、把 AI 用价压下来，以后新模型的推理代码也会放进这个仓库。宝玉的中文解读补充了门槛：它只能跑在英伟达 Blackwell 一代数据中心显卡或华为昇腾 950 上，官方测试用了 4 到 64 块卡，个人电脑跑不动，真正用得上的是想自己部署 DeepSeek 的企业和云厂商。

核心要点

  • 主要提速手段是投机解码：先让一个轻量的草稿模型一次猜出后面最多 5 个 token，大模型一次性核对，猜对的直接收下、猜错的才重算。
  • 这次放出的只是离线推理部分，缓存对话前文的 KV cache 系统、把读输入和写输出拆到不同机器的 PD 分离、多副本之间的流量调度都没有包含，要搭完整线上服务还得自己补。
  • deepseek-recipe 像前台接单员，把 OpenAI 和 Anthropic 格式的请求翻译成 DeepSeek 能读的输入，再把思考过程和工具调用翻译回去，让自建部署的行为和官方 API 一致。
  • 授权很宽松：DeepInfer 用 Apache 2.0、deepseek-recipe 用 MIT，都允许免费商用和修改；recipe 有 Python 和 Rust 两个版本，支持 V4 和 V4.1。
  • Orange AI 的说法是，用上这套框架后自建推理的回本周期从约 10 个月缩到约 4 个月，这是作者转述的估算，不是 DeepSeek 官方数字。

全球每年约有 120 万人被蝎子蜇伤，而抗蝎毒血清往往又贵又缺。Anthropic 和研究机构 Citrini 合作，让 Claude 针对五种蝎子神经毒素设计能结合上去的蛋白质，瞄准的是毒素用来抓住细胞的那一部分。Claude 在 64 小时里生成了 30 多万个设计方案，团队从中挑出 211 个交给 Adaptyv Bio 和 Twist Bioscience 合成并做湿实验，其中 17 个达到结合蛋白的标准，能结合墨西哥、北非和中东蝎子的毒素，但对一种巴西蝎子无效。Anthropic 公开了全部 211 个送检设计和实验数据，并明确说这只是探索性工作，并没有做出抗毒血清，后面还要做细胞实验、小鼠实验等很多步骤。

核心要点

  • AIGCLINK 转述的技术报告细节是：表现最好的两个候选针对墨西哥蝎毒 Cn2，在两家实验室都测出个位数纳摩尔级的结合亲和力，也就是结合得相当牢。

Hamel 实测 6 个决策模型做自动评测：别直接用 0.5 的默认阈值，先调阈值再比性价比↗

Hamel Husain @HamelHusain6.2万 粉丝10月21日 00:54X 长文

赞 1,376转 0评 87阅 13.6万

推荐原因你一直关心 harness 和评测，这篇把“怎么选裁判模型、怎么定阈值”讲成了一套能照做的流程，文中的提示词可以直接交给编程 agent 跑。

最近出现了一批专门做二分类判断的“决策模型”，比如 TypeSafe 的 Jev、Perplexity Decider、Liquid d1、Cloudflare Clef 和 OpenAI Decisions API，它们比用大模型当裁判更快、更便宜，适合用来给 AI 应用做自动评测（eval）。Hamel Husain 和 Antaripa Saha 用一个租房客服 agent 的 100 条对话记录做测试，让每个模型判断哪条记录里出了错，比如订房失败或没有及时转人工，再和人工标注对比。文章的核心提醒是：很多人直接用接口默认的 0.5 阈值，结果白白丢掉不少效果；正确做法是先定好最低的准确率和召回率要求，再用交叉验证调阈值，最后才比较成本。文中还附了两段可以直接交给编程 agent 执行的调阈值和校准提示词。

核心要点

  • 阈值的坑可以用一个例子说明：如果模型给所有出错记录打 0.40、给正常记录打 0.10，阈值设 0.30 能全部分对，用默认 0.50 却一条错误都抓不到。
  • 作者把精确率和召回率都至少 80% 作为可用门槛，只有 Perplexity、Liquid d1-ultra 和 OpenAI Decisions 达标；调阈值时用分层五折交叉验证，在训练折上选阈值、在留出折上评估。
  • 成本对比上，Perplexity 每 100 次评测约 0.82 美分、F1 为 0.79，OpenAI Decisions F1 达到 0.87 但每 100 次约 3.72 美分，大约贵 4.5 倍。
  • 分数能不能当概率用也要先查校准：Clef Flash 有一组记录平均预测出错概率约 8%，实际却有 60% 出错；用 Platt 缩放校准后多数模型改善，但 OpenAI 的反而略变差。
  • 作者建议每种失败类型单独建一个裁判，先用效果够好的大模型，再试小模型能不能以更低成本追平；不同任务上的排名差异很大，必须用自己的数据测。

评论总结

  • 共识多位读者（如 @MelvinRoyV、@botmancer）认同调阈值是最常被跳过的一步，并补充阈值应该跟着出错的代价走，退款场景漏判和摘要场景漏判不是一回事。
  • 疑问@kartikb753 追问阈值是不是在同一批租房对话上调又在同一批上打分，有人引用文章脚注回答：用的是重复五折交叉验证，在训练折选阈值、在留出折评估。

elvis 实测 agent 共享记忆：Claude Code 做到一半存进共享空间，新开的 Codex 读完直接接着干↗

elvis @omarsar032.5万 粉丝10月20日 23:55X 长文

赞 139转 0评 7阅 1.6万

推荐原因你在搭需要长期运行的个人 agent，这篇给了一个可以照着复现的多 agent 交接测试；它带推广性质，更值得借鉴的是“记忆放在会话外、自己掌握”的思路。

elvis（@omarsar0）认为，除了模型和 harness，agent 的记忆也是你应该自己掌握的一层，尤其是要连续跑好几天的长期任务 agent。常见做法是记忆只存在某一个工具、某一台机器里，换一个 agent 就看不到前一个学到了什么。他试用了 Fulcra 提供的共享上下文层，做了一次真实交接：先让 Claude Code 完成一个小编程任务的第一步，并把进度、做过的决定和下一步写进共享工作区；再新开一个 Codex 会话，只告诉它工作区名字。Codex 读完后判断出哪些做完了、哪些没做，直接完成剩下两步，测试全部通过，中间没有手动粘贴任何内容。需要注意，这篇文章是与 Fulcra 合作的推广内容，文末附了试用链接。

核心要点

  • 他举的背景例子是：四个 Gemini 4 Argon agent 通过共享记忆交换物品、策略和经验，27 小时打通了 Minecraft，说明模型越来越会自己决定该记住什么。
  • 长期 agent 会被重启、换模型、上下文用完，如果状态存在会话外面，新会话读一遍就能知道进展，这是 agent 能持续工作好几天的前提。
  • 共享空间可以按文件夹控制谁能看到，比如只把一个文件夹共享给某个人或他的 agent，其余保持私有，数据也能随时导出或删除。
  • 想试的话可以用 npx skills add fulcradynamics/agent-skills 给 agent 装上对应技能，不过同类做法也可以用 git 里的普通文件实现，评论区就有人这么做。

评论总结

推荐原因你之前对代码做视频的技能标过有用，这篇把各种风格背后的技术名词和工具一次讲全，写提示词时可以直接点名对应技术。

最近很多人用代码做视频来起号或做宣传，3D 小岛、水彩 MV、手绘线条各种风格都有。空格研究后把原理讲清楚：视频模型是直接生成每一帧的像素，而代码路线是让模型写一个“给定时间、返回一张画面”的函数，渲染器从第 0 帧开始逐帧调用、截图，最后用 FFmpeg 拼成 MP4 并配上声音。相比视频模型每次抽卡结果都不一样，代码渲染 100 次结果完全一致，想把标题挪 20 像素改一个数字就行，这种可复现、能精确修改是它最实在的好处。文章把方法分成四类 9 种，每种都附了开源地址和教程链接，最后给出选择建议和对比表。

核心要点

  • 最主流的一类是把画面写成网页再让无界面浏览器截图，包括 HeyGen 开源的 HyperFrames、用 React 写视频的 Remotion，以及按时间顺序写剧本的 Motion Canvas，原因是模型写网页最稳、出错最少。
  • 要去掉“像 PPT”的 AI 味，可以用 rough.js 给线条加随机抖动做出手绘感，或者把插画拆成几层错开出场，水彩效果则是把同一个不规则形状叠 40 多层、每层只有 4.5% 不透明度。
  • 数学讲解用 Manim，把曲线和公式都当成数学对象做插值动画；地图路线是先做好配音、用 TTS 拿到每句话的时间戳，再让路线进度跟着口播走，作者自己做了接高德地图的 map-motion 技能。
  • 3D 方向有两条路：three.js 在网页里搭场景，关键是让镜头沿一条平滑曲线移动；黏土质感或真正的 3D 角色则用 Blender MCP，让 AI 直接操作 Blender 加物体、换材质、打关键帧。
  • 如果只学一个，作者推荐 HyperFrames：开源生态最丰富、现成技能多，而且 rough.js、p5、three.js 这些库都能塞进它的网页里一起渲染。
