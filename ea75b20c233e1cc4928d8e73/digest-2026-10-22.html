Node.js 三条版本线修高危漏洞，最严重的可远程执行代码，20.x 和 25.x 没有补丁↗

宝玉 @dotey26.1万 粉丝10月22日 08:38长帖

赞 132转 0评 34阅 2.8万

推荐原因你的 agent 和小工具很多跑在 Node 上，尤其是会抓外部网页的服务正好可能踩到解压漏洞，值得今天就用 node -v 查一遍。

用 Node.js 跑服务或写工具的人这周要换版本了。10 月 21 日 Node.js 给还在维护的三条版本线发了安全更新：22.x 升到 v22.23.4，24.x 升到 v24.22.1，26.x 升到 v26.12.1。最严重的漏洞在 Node 自带的 Brotli 解压组件里，Brotli 是网页传输常用的压缩格式，这个组件会把数据写到不该写的内存位置，官方说可能被用来远程执行代码。另外三个漏洞出在 HTTPS 证书核对上，都和 IP 地址写法有关，比如用全角数字写的 IP 可能让核对被绕过。20.x 和 25.x 已经停止维护，这次没有补丁，还在用的只能迁到 22、24 或 26。这一版还内置了一份证书黑名单，第一批放进去的就是前几天曝出的 eMudhra 8 枚坏证书。Vercel CEO Rauch 也在同题帖里说，Vercel 在官方补丁前就给所有部署加了防火墙规则。

核心要点

  • dns.resolve 还有一个高危问题：域名中间夹着空字符时，Node 会在那里截断，实际只查了前半截。
  • 用启动快照或打包成单个可执行文件（SEA）的要注意：randomUUID 和 randomInt 的随机数缓存会被一起存进包里，导致每次启动都生成同样的“随机”值。
  • eMudhra 那 8 枚中间证书的私钥极弱，谁拿到都能给任意网站签假证书；Chrome、Firefox 17 日当天拉黑，Node 到 21 日才发版，旧版 Node 照样会放行这些假证书。
  • Mozilla 工程师 Dennis Jackson 做了一个自查网站，可以测自己的程序还认不认这几枚坏证书。

宝玉读了 Every 的长文《How Codex Happened》，最有感触的是 Codex 桌面应用的来历。当时流行的是 Cursor 这种把聊天塞进编辑器的做法，Tibo 却决定做一款原生桌面应用，理由是模型能做的任务越来越长，人们很快会同时开好几个 agent、一整天都和它们待在一起，需要一个丰富的界面。他找来设计师兼程序员 Andrew Ambrosino，没有像 Cursor 那样从 VS Code 分支出来，而是参考聊天软件：左边是任务，每个任务一个 agent，右边是对话。最冒险的决定是应用里不放代码编辑器，想改代码只能让 agent 去改，因为四人小团队不可能做出一个好编辑器，Codex 必须好到让你不想念编辑器。一开始内部没人主力用它，直到 11 月 GPT-5.1-Codex-Max 和 12 月 GPT-5.2-Codex 发布，情况才翻转，2 月 Codex 应用在 OpenAI 内部流行开来。

核心要点

  • Ambrosino 每天进办公室都挨个问同事“你在主力用 Codex 吗”，一开始所有人都说没有，还有人抱怨为了改一句话也得去提示 Codex。
  • 2025 年 11 月 Google 发布把 agent 和完整编辑器结合的 Antigravity，Ambrosino 一度怀疑“我们是不是犯了一个巨大的错误”。
  • 转折点是独立的 Codex 模型线：GPT-5.2 发布后，那位抱怨的同事改口说现在大多数改动只留一条行内评论；研究员 Noam Brown 完全切换，Brockman 说回到终端加 Emacs 像穿越回过去。
  • 宝玉也提醒，Codex Cloud 当初在内部同样很受欢迎，一发布却扑了街，所以内部喜爱不等于市场成功。
