Harness 指的是包在模型外面的那一层：提示词、工具、流程和记忆，决定 Agent 怎么干活。Google 这篇论文研究的是在干活过程中改进这一层，而且不需要一个能判断对错的“裁判”。做法是：针对当前任务提出几种对工作方式的修改，让它们互相比较，留下效果最好的组合；这些修改里学到的经验，再写进一份 Agent 随身带到下一个任务的“经验版”工作方式。结果：GLM-5 和 Gemini 3.5 Flash 在三个测试集的所有配置下都有提升，同时并行试 5 种修改还能再多 3 到 4 分；而作为对比的一种记忆方法，在写代码任务上反而比不改还低了 6.6 分。

核心要点

  • 测试时、无 verifier 的 harness 进化
  • 当前任务内比较多个改动，留最佳组合
  • 经验写进跨任务携带的第二套 harness
  • GLM-5、Gemini 3.5 Flash 全配置提升；5 个候选并行再 +2.9–3.9 分；ReasoningBank 记忆基线反而掉 6.6 分

Anthropic 因为 Claude 写代码太快，每天合并的代码从 2500 次涨到 3 万次，传统 Git 撑不住，于是自己做了一套叫 Scion 的版本管理系统。现在有网友用 Rust 独立复刻并开源，从提交、按需下载部分代码、查历史到多人同时合并都跑通了。核心思路是分工反过来：完整历史和提交、合并都放在服务器上，每个 AI Agent 只下载手头任务需要的那几个文件，不用把整个仓库拷到本地。在苹果 M4 Pro 上用 1000 到 1 万个文件测试，导入目录比 Git 快 7.8 到 11.5 倍，完整下载快 1.4 倍，但提交单个文件仍比 Git 慢。

核心要点

  • 从本地优先转向面向在线 Agent 的服务端优先
  • 客户端按需稀疏检出
  • 导入快 7.8–11.5 倍，单文件提交仍慢
  • 下一步：区域缓存、快照引导、虚拟化检出

评论总结

  • 共识大家惊讶于复刻速度之快，也认同 Agent 时代的版本管理会成为独立赛道：Git 的“本地优先”设计从没考虑过每天 3 万次合并这种量级。
  • 分歧有人指出只测小仓库的导入速度看不出 Scion 真正的好处，原版很多任务直接调服务端查历史、根本不用下载代码；还有人认为难点不在存储而在冲突裁决，十个 Agent 同时改一个文件，传统合并方式扛不住。

换了更快的显卡，AI 吐字却没变快？问题出在 CPU 来不及“派活”↗

Avi Chawla @_avichawla7.9万 粉丝10月15日 17:40长帖

赞 110转 18评 15阅 5,503

推荐原因推理变慢的经典坑讲得很清楚；你本地部署模型时可以确认推理框架（vLLM、TensorRT-LLM 等）是否开了 CUDA Graphs。

一道 AI 工程面试题：模型、精度、批量都没变，换到更快的 GPU 后每个计算步骤确实快了，但生成每个字的间隔几乎没变。原因是：生成一个字要依次跑注意力、矩阵乘法、归一化、采样等一长串小计算，每一个都得由 CPU 单独准备好再交给 GPU。有些小计算 GPU 几微秒就做完了，CPU 却还没把下一个递过来，GPU 只能干等。解决办法叫 CUDA Graphs：把这一串操作先录下来，之后每次整串一次性交给 GPU 重放，省掉逐个派活的等待。

核心要点

  • 瓶颈在 CPU 逐个提交 kernel 的开销
  • 小 kernel 让 GPU 空等
  • CUDA Graphs：捕获一次、整图重放
  • kernel 本身并不会变快

评论总结

  • 分歧不少人认为主因其实是显存带宽：逐字生成本来就受内存速度限制，算得再快也没用，不换更快的显存 tok/s 不会动；CUDA Graphs 解决的是另一层开销。
  • 亮点有人补充：显卡越快，这些空等的间隙在每个字里占比越大；不用推理框架的话，PyTorch 里 torch.compile(mode="reduce-overhead") 就能打开 CUDA Graphs。

美国通胀数据超预期，美股和比特币为什么反而涨了↗

推荐原因把一晚上的数据和行情串成了因果链；之后判断走势时盯 PCE 预测和 10 年期美债利率，比只看通胀头条数字更有用。

9 月美国生产者物价（PPI）比上月涨 1.3%，预期只有 0.5%，看上去很吓人，但美股和比特币先跌后涨。Phyrex 的解释：一，美联储真正看的是另一个通胀指标 PCE，机构根据 PPI 细项重算后，对 PCE 的预测并没有一致大幅上调；二，零售销售涨 0.8% 看着强，但七成来自加油站（油价涨了），剔除后基础消费只涨 0.1%，说明需求在变弱，美联储继续加息要更谨慎；三，10 月加息的概率从前一天的约 45% 降到约 27%，10 年期美债利率也从 5.3% 以上回落到约 5.04%，而这些变化在 PPI 公布前就开始了。所以这轮上涨更像是加息担忧缓和后的修复，通胀问题本身并没解决。

核心要点

  • PPI 超预期没有传导成 PCE 预测大幅上调
  • 零售强在油价，控制组仅 +0.1%
  • 10 月加息概率约 45% → 27%
  • 资金因 AI 企业债务担忧买国债避险，收益率回落减轻估值压力

评论总结

  • 共识懂行的读者补充：PPI 被单月涨超 10% 的能源价格顶高，但美联储看的是 PCE，油价这一截传过去要打折；后面两年期国债利率回落、10 月加息预期没再升，才是行情松绑的原因，别把反弹理解成通胀消失。
  • 分歧看空的人认为加息并没有结束，只是押到了 12 月，押降息是“拿头接飞刀”；也有人说这只是“利空出尽”的安慰剂，吃多了会失效。
